# 公开访客预览

部署环境可通过 `PUBLIC_PREVIEW_USERNAMES` 指定预览账号，多个用户名以逗号分隔，默认不开启。无需给该账号管理员角色。

预览账号的用户信息包含 `is_preview` 和 `preview_permissions`。后者仅供前端展示页面、按钮和表单；后端实际权限仍限制为查看与观测查询，凭据明文不开放。

- 前端在 Axios 发送前拦截保存、执行、审批、删除、终端命令等请求，显示访客体验提示。
- 后端 Token 和 Session 认证均在进入处理函数前拒绝非读取请求。少数通过 POST 提交的日志、指标、链路查询、关联跳转和退出登录使用显式路由白名单。
- 系统 SLA 历史接口通过 GET 的 `refresh` 或 `backfill` 参数执行重算、补录时，同样在前后端拦截；普通历史查询保持可用。
- 原来与执行权限共用的任务列表、任务模板、任务统计、资源选项和用户授权配置查看接口，只对指定 GET 路由开放。
- WebSocket 终端继续检查后端实际权限，无法通过界面预览权限建立命令执行连接。
- 修改角色或超级管理员标记不能突破预览账号的后端权限上限。未列入配置的用户沿用现有 RBAC。

验证：`python manage.py test rbac`、`node frontend/scripts/test-public-preview.mjs`、`npm run build`。

生产启用前先备份配置，设置环境变量后重建应用和异步工作容器，再验证访客读取、直接接口写入拒绝及管理员操作。
