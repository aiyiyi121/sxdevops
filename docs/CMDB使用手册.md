# CMDB 使用手册

CMDB 管理资产事实、业务归属、关系、采集与治理；任务资源底座管理可执行连接。资产登记后不会自动变成执行目标，接入方式见[任务资源与 CMDB](task-resource-cmdb.md)。

## 页面入口

当前主要入口如下。菜单显示还受账号权限和系统设置影响，标记“待完善”的页面默认隐藏，不能视为全部能力已投产。

| 入口 | 用途 |
| --- | --- |
| 概览 | 资产盘点、CPU / 内存 / 磁盘水位、成本与治理摘要 |
| 资产台账 | 按业务线、环境、分类、状态和标签搜索资产，查看详情及关系 |
| 分类视图 | 按模型分类浏览资产及拓扑 |
| 资产治理 | 查看归属缺失、数据质量和资源治理建议 |
| 成本管理 | 按业务线、环境、类型和供应商汇总已登记成本 |
| 平台配置 | 资产采集、分类配置及 IP 管理 |

## 首次接入

1. 配置业务线和环境等资源归属，约定稳定的环境标识。
2. 在“平台配置 → 资产采集”选择内置模板，新建或配置采集任务。
3. 在预览中检查来源、目标模型、标识、归属和字段映射，再执行一次采集。
4. 在“资产台账”确认类型、名称、IP、规格、负责人、生命周期和指标来源。
5. 需要周期采集时启用任务，并确认 CMDB 调度器正在运行；手工采集成功不代表定时服务已启动。

模板支持 vSphere VM、阿里云 ECS / RDS / 中间件、华为云 ECS / RDS / Redis、机房服务器和第三方服务登记等。实际可用项取决于当前模板、连接权限及云侧能力。

云账号在多云管理中维护，采集配置引用 `cloud_account_id`，不在任务 JSON 中粘贴 AK/SK。vSphere 可用 `auth_ref` 引用运行环境凭据，例如 `SXDEVOPS_VSPHERE_PROD_PASSWORD`；页面预览或执行时也可按提示使用一次性密码，不把它保存到任务配置。

第三方服务登记合同、负责人、到期和归属信息，不把 API Key 当作普通资产字段保存。机房服务器登记资产号、管理 IP、机柜、U 位、厂商、型号及规格。

## 资产与登录凭据

资产台账按分类、业务线、环境、状态、标签或名称/IP筛选；详情查看基本属性、变更记录、资产水位和关系。补齐负责人和归属后再进行治理分析，避免用不完整台账判断业务影响。

“登录凭据”使用独立密文表。启用前配置并备份 `CMDB_PASSWORD_ENCRYPTION_KEY`，各实例使用相同密钥；丢失或更换密钥会导致历史密码无法解密，见[配置参考](configuration.md#密钥与访问入口)。查看、管理及资源范围按实际授权控制，列表可见不等于可以导出密码。

资产生命周期与连接状态分别维护：任务 SSH 失败不自动将资产下线；资产停机或下线会阻止关联执行资源的新任务。

## 指标与容量

水位来源于采集快照，详情应同时核对采集时间、来源、单位和缺失项。当前快照读取按每项资产、每类指标选最新记录；历史均值与当前水位不是同一口径。

vSphere 默认采集清单和规格，可接入 Prometheus / node_exporter 获取 CPU、内存和根分区使用量；缺失项按规则回退并标注来源，配置见 [vSphere 指标接入](vsphere-vm-prometheus-metrics.md)。无数据、过期数据或采集失败不能当作资源健康或空闲。

## 关系与拓扑

关系用于表示运行承载、连接和依赖，如 `runs_on`、`connects_to`、`depends_on`。从应用追查依赖，或从主机反查承载服务时，同时确认关系方向和维护时间。

拓扑可只展示命中节点，或扩展最多三跳邻居；只展示授权资产及对应关系，图例跟随实际类型变化。没有展示某个节点可能是数据缺失或无权查看，不能据此断言不存在依赖。

## 治理与成本

治理建议用于定位归属缺失、低利用率、闲置或规格不匹配等候选项；先检查数据完整性与采样窗口，再由负责人确认。建议本身不会自动完成资源回收。

成本管理基于平台已登记的成本及规格信息汇总；缺失价格、账单或归属时不代表真实成本为零，也不代表已与云账单对账。资源申请等标记“待完善”的入口需按实际开放范围使用。

## 接入验收与排障

- 采集预览与执行记录可追溯，目标模型和唯一标识正确，没有重复资产。
- 台账归属、规格和负责人合理，凭据未混入普通字段或审计内容。
- 水位显示时间和来源，已区分真实指标、回退指标和缺失项。
- 普通账号只能查看授权资产，关系、选择器和任务接入同样遵守范围。
- 需要执行时从任务资源显式接入，补充执行凭据，验证停机/下线拦截。

周期采集失败先看调度器、任务状态与采集记录，再检查连接、权限和字段映射。凭据解密失败先核对原加密密钥，不能通过生成新密钥修复旧密文。
