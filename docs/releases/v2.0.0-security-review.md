# v2 后续安全与依赖核对

核对日期：2026-10-30。本文对应 `codex/v2-validation-fixes` 的后续修复，不代表已发布的 `v2.0.0` 标签内容发生变化，也不代表已经部署。

## 凭据历史

使用官方 Gitleaks 8.30.1，下载文件与官方 SHA256 清单一致。默认规则扫描截至 `302ae70` 的 183 个提交，共报告 4 处：

| 发现 | 处置 |
| --- | --- |
| Compose 中同一默认 Fernet 密钥的 3 个引用 | 当前源码移除，三个服务改为要求外部提供持久密钥；历史提交仍可读取，按已公开值处理 |
| 运行时生成的验证租约 `claim_token` 更新代码 | 人工核对为 UUID 变量赋值，无静态凭据；没有添加宽泛忽略规则 |

当前候选源码再次扫描仅报告上述动态 UUID 代码。扫描采用默认检测规则，不能证明不存在所有类型的凭据或私有信息。

已有部署若使用过公开默认密钥，仍需在其实际环境完成备份、旧密文解密、新密钥重加密及三个服务同步验证。源码修复不代表线上轮换完成。已发布标签与历史保持稳定，没有改写 Git 历史；不得因此继续把旧默认值当作秘密。

## 依赖许可

本地环境核对 139 个 Python 依赖和 88 个前端生产包，具体版本和文本来源见[许可清单](v2.0.0-dependency-licenses.json)。项目没有修改第三方库源码；Paramiko 的 LGPL、Certifi 及 orjson 中 MPL 覆盖部分保留各自义务。

前端构建自动生成 `/assets/third-party-notices.txt`，缺少声明时阻止构建；两个 npm 包使用精确版本补充文件。Python 发行文本和补充文件见[第三方声明](../../THIRD_PARTY_NOTICES.md)，容器保留 `.dist-info` 文本并复制 `/app/licenses/`。四个 Alibaba Python 包的 wheel/sdist 未附许可文件，补充材料保留其发布者声明及标准 Apache-2.0 全文，未声称恢复缺失的上游 NOTICE。

清单是本地已安装依赖的审计结果。Python 版本约束仍允许后续解析出不同版本；构建实际镜像时须重做依赖清单和许可证核对，不能把本轮清单视为所有未来构建的合规证明。
