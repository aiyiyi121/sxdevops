# 前端主题

侧栏底部的主题按钮打开三种配色选项，收拢侧栏后仍可使用。图标表示当前主题：浅色显示太阳，两种深色显示月亮；菜单用色板、名称和勾选标记显示当前选择。

| 配色 | 保存值 | 视觉方向 |
| --- | --- | --- |
| 浅色 | `light` | 保留原有白色工作台 |
| 炭灰（推荐深色） | `charcoal` | 中性灰背景、卡片和表单，保留蓝色操作强调及状态色 |
| 深蓝灰 | `dark` | 保留原有蓝灰背景与分层卡片 |

首次访问默认浅色，选择保存在浏览器 `sxdevops-theme` 中，同源标签页同步变化。旧的 `dark` 偏好仍对应深蓝灰。入口 HTML 提前恢复三种主题，两种深色都使用浏览器的 `dark` color scheme，避免刷新闪白。

菜单按浅色、炭灰、深蓝灰排列，炭灰标记为推荐深色。推荐只影响展示顺序与标记，用户仍可在侧栏底部的主题菜单直接选择深蓝灰，已保存的选择不会被覆盖。

## 配色与适配

- `frontend/src/theme/index.js` 管理主题状态、持久化与变更事件。
- `frontend/src/theme/palette.js` 定义深蓝灰与炭灰色板，以及文字、背景、边框、阴影四种颜色转换规则。
- `frontend/src/assets/theme.css` 维护 Element Plus 变量和组件细节，覆盖弹窗、输入框、表格、标签、按钮、选中态、焦点态与禁用态。
- `frontend/build/workbench-theme.js` 在 Vite 的 PostCSS 阶段将项目自身 CSS 的固定颜色转换为 `light-dark(原色, 深色变量)`；变量默认值保留深蓝灰，炭灰主题覆盖共享色板变量。浅色值保持原样，不转换第三方样式、图片和 URL。新增页面可直接复用现有工作台结构。
- 内联动态颜色通过 `themedColor(value, role)` 生成 CSS 主题色；Canvas 使用 `resolveThemeColor(value, role)`，并在主题变化后重绘。
- 公共 ECharts 入口保留原始图表配置，切换时更新背景、标签、坐标轴、图例及提示框；Grafana 内嵌页通过 `theme=light/dark` 跟随平台主题，两种深色均映射为 Grafana 支持的 `dark`。

文字色与填充色分开处理：深色状态文字使用较亮颜色，实心按钮使用较深背景搭配白字。普通正文、辅助文字与状态文字的目标对比度至少为 4.5:1；输入框、焦点与选中态同时保留清晰轮廓。日志、终端及代码区保持深色，炭灰主题将其中的蓝灰背景调整为中性深灰。

智能助手输入区使用外层容器统一显示边框与焦点，深色主题中的内部文本框不再单独描边，包括悬停、聚焦与禁用状态。

## 开发验证

使用支持 CSS `light-dark()` 的现代浏览器，例如 Chrome / Edge 123 或更高版本。主题构建插件的依赖安装后，如开发服务器首次重启失败，重新启动 Vite。

运行 `cd frontend && npm run build`，并在三种主题下检查列表、空状态、弹窗、下拉菜单、输入框、状态标签、图谱、图表和聊天内容；同时检查侧栏收拢及窄窗口。刷新页面和切换同源标签页时应保持主题一致。

外部嵌入页由对应服务提供主题支持，平台样式不直接修改跨域 iframe 的内部 DOM。
