# 任务资源底座与 CMDB 接入

资源底座只展示已经保存的执行资源。CMDB 新增、同步或发现的资产不会自动接入；手工添加的执行资源也不会反向创建 CMDB 资产。

## 接入方式

- **从 CMDB 接入**：在资产选择器中搜索主机、虚拟机或 K8s 集群，选择一项后补充执行信息并保存。仅浏览或选择后取消不会创建执行资源。每项 CMDB 资产只能接入一次。
- **手工添加**：填写主机连接或选择已有 K8s 连接，来源标记为“手工添加”。适合尚未登记 CMDB 的资源。

CMDB 接入要求同时拥有 `ops.task.resource.manage` 和 `cmdb.ci.view`，并遵守 CMDB 资源范围授权。资源列表和接入选择器支持分页；资源列表可按来源筛选。

资源底座与接入选择器均提供与 CMDB 一致的“业务线 → 环境”树，可点击业务线或环境筛选。CMDB 节点保留原有层级，资源底座的节点数量只统计已接入的执行资源，接入选择器则统计当前有权查看的可选资产；保留空节点不会自动接入资产。历史文本归属和手工资源的系统、环境也纳入树中，缺少业务归属的资源集中在“未归属业务线”。鼠标悬停树标题或节点时显示可用操作：CMDB 节点由拥有 `cmdb.ci.manage` 的资源管理员维护，与资产台账同步生效；同步来源节点只允许调整排序。手工环境和系统通过对应节点的悬停操作维护，空手工分组也保留在树中。“执行资源”标题右侧只显示主机、K8s、可用和异常统计。

## 信息维护

CMDB 已填写的名称、有效 IP、负责人、说明、SSH 用户和端口沿用资产台账。CMDB 缺失的字段允许在资源底座补充，补充内容不会写回 CMDB。任务执行密码在资源底座补充，不会从 CMDB 密码接口导出或复制。

源资产保存更新时，仅同步 CMDB 已提供的基础字段，保留资源底座补充的缺失字段和执行密码。CMDB 后续补齐某个字段后，以新的 CMDB 值为准。K8s 资产仍需选择容器环境中已经配置的集群连接。

CMDB 已有环境和系统归属会在显式接入时映射到任务资源树；有 CMDB 节点的归属通过节点 ID 关联，节点更名时同步展示名称。CMDB 未提供归属时，可选择任务资源树中的环境和系统。现有资源、分组、任务记录及计划任务引用不做自动迁移或重新匹配，历史手工资源保持原 ID。

## 移除与生命周期

- 在资源底座移除接入只删除执行资源，保留 CMDB 资产；该资产随后可以重新接入。
- CMDB 资产停机或下线时，资源底座显示“暂停执行”，阻止新的关联资源任务执行。
- CMDB 资产删除时，保留执行资源及“CMDB 接入”来源标记，显示关联失效并阻止执行；可移除后重新接入。
- 任务执行状态和资产生命周期分别维护，任务连接失败不会直接修改 CMDB 资产生命周期。
