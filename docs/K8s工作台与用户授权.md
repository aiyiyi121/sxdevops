# K8s 工作台与用户授权

本文说明资源工作台、集群及命名空间授权、YAML 预检、日志和交互终端。平台部署与工作台管理的目标集群是两件事；部署 SxDevOps 本身见 [Kubernetes 部署指南](Kubernetes部署指南.md)。

## 功能入口

- 容器管理 → K8s 集群：保留集群、节点、命名空间、工作负载、网络、存储和配置管理。
- 网络管理：支持 Service、Ingress、Endpoints、IngressClass、NetworkPolicy，提供列表与 YAML 创建、查看、编辑和删除。Endpoints 展示 Ready / NotReady 地址与端口；IngressClass 展示 Controller 和默认类状态。
- 扩展资源：支持 HPA（autoscaling/v2）、ResourceQuota、LimitRange，二级标签统一使用英文资源名，位于列表卡片右上角。
- YAML 查看弹窗仅保留代码窗口内部滚动，避免长 YAML 产生双层滚动条。
- YAML 创建 / 编辑：支持单个资源，先预检并显示差异，再确认应用。真实集群调用 Kubernetes dry-run；更新保留 resourceVersion，并检测预检后资源变化。
- YAML 创建按当前页面及子标签生成对应资源模板，覆盖节点、命名空间、工作负载、网络、存储、配置和扩展资源。命名空间级模板使用当前命名空间；全部命名空间视图使用首个授权命名空间或 default；节点、命名空间、PV、StorageClass、IngressClass 模板不携带 namespace，创建入口仅对完整集群管理员显示。
- 节点列表内存统一按 1024 换算为 G，最多保留两位小数，兼容 Kubernetes 返回的 Ki、Mi、Gi 等容量单位。
- YAML 更新使用完整资源替换，编辑时保留需要的字段；预检期间锁定文本输入，避免预检内容与应用内容不一致。
- 资源菜单：支持删除资源、Deployment / StatefulSet / DaemonSet 滚动重启、CronJob 暂停 / 恢复、节点禁止 / 恢复调度。删除前确认，系统命名空间禁止删除。
- 自动刷新：手动、15 秒、30 秒或 60 秒；页面隐藏时停止轮询，离开页面清理定时器。
- 资源列表默认每页 50 条，可切换 20 / 50 / 100 条；搜索覆盖当前资源的全部已加载记录，再对结果分页。工作负载的 Pod 弹窗也按每页 50 条展示。
- 行操作菜单按需挂载，关闭后释放菜单节点。资源列表与概览、命名空间并行刷新，切换集群或命名空间后忽略旧请求结果，同一上下文的并发请求合并。
- 完整集群概览最多并发 4 个资源查询，避免 13 个查询串行累积等待；部分资源超时或无权限时继续显示可用统计，并保留降级提示。
- 选中集群的右侧概要使用表格展示 CPU、内存容量，不绘制环形图。CPU 使用核数、内存使用 MiB / GiB；同时列出实际用量、Requests、Limits、可分配和总容量，保留用量占比与超配提示。Requests / Limits 按已调度且未结束的 Pod 汇总，包含 init 容器、常驻 init sidecar 和 Pod overhead。Pod 指标放在表格下方的小卡片中：第一行依次为 Ready 节点、工作负载、PVC Pending，第二行依次为 Pod 容量、Pod 用量、异常 Pod；Pod 用量排除未调度和已结束实例。桌面侧栏宽度最多 460px，左侧按三列等分可用宽度，卡片随窗口伸展，窄屏自适应排列；省略空描述与重复连接状态。
- 容量接口独立缓存 30 秒，最多并发三个采集请求，不阻塞集群列表或普通资源页面。实际用量来自 `metrics.k8s.io/v1beta1` 节点指标；缺失、拒绝或采样不完整时显示不可用，不填充为零。采集需要 kubeconfig 对节点、Pod 和节点 metrics 的读取权限。
- 容量沿用 `ops.k8s.view`；后端在读取缓存前校验完整集群范围，命名空间受限用户不会请求或展示整集群容量。
- 集群控制台与 Pod 终端统一为自适应交互窗口，支持全屏、容器与 Shell 选择、复制选中、粘贴、清屏、重连和会话下载。后端确认 Shell 就绪后才显示已连接；关闭窗口释放 WebSocket 与终端，会话退出及时显示断开。终端使用直接 WebSocket 通信，不订阅共享 Redis 通道，避免通道接收超时中断交互；集群 Shell 具有控制 TTY，支持中断和终端尺寸调整。
- Pod 日志首次只读取最近 500 行，向上翻阅时按需采集容器保留的历史，通过签名游标双向翻页，浏览器最多保留三个页面、每页最多 500 行或 512 KiB。历史流分块写入服务端临时文件，不在应用内存中积累全量日志；临时文件保留 15 分钟，后续采集清理过期文件。展示容器原始日志，不附加 Kubernetes 时间戳。支持容器切换、上次运行、刷新、回到最新、复制当前窗口与全屏。可查看的最早时间受 Kubernetes 容器日志轮转与保留策略限制。
- 终端不提供预设命令菜单，Tab 直接发送给当前交互 Shell。集群终端默认使用 Bash，并加载系统 bash-completion 与 `kubectl completion bash`，由工具自身生成子命令、参数和资源名称候选。Pod 默认优先 Bash，缺失时回退容器原有 `/bin/sh`；选择 Bash 时保留容器 `.bashrc` 与已配置的补全，再按需加载 kubectl 补全。Pod 镜像需自带所用 Shell、工具及其补全依赖，平台不在容器中安装软件或持久化补全脚本。

## 权限配置

系统管理 → 用户管理 → 用户行的「K8s 授权」。配置人员需具备 `rbac.user.manage`，同时满足[委派管理权限上限](user-permission-security.md#用户角色与用户组)。具有 K8s 范围限制的管理员不能扩大他人的平台能力或资源范围。

平台角色中的 `ops.k8s.view`、`ops.k8s.manage`、`ops.k8s.exec`、`ops.k8s.kubectl`、`ops.k8s.terminal` 是能力上限；用户集群授权只能进一步收紧，不会自动授予平台权限。

| 配置 | 行为 |
| --- | --- |
| 沿用平台角色范围 | 兼容已有账号，继续按平台权限访问集群 |
| 指定集群，无授权行 | 禁止访问全部集群 |
| 只读 | 查询授权资源，禁止写入和 Pod 终端 |
| 运维 | 在授权命名空间内创建、更新、删除及操作资源 |
| 管理员 | 可管理资源；完整集群范围时可维护连接、节点调度和使用集群命令/终端 |
| 命名空间留空 | 全部命名空间；指定名称则仅可访问对应范围 |
| Pod 终端 | 额外开关，同时需要 `ops.k8s.exec`，只读角色不能开启 |

命名空间受限用户不展示节点、PV、StorageClass、IngressClass；概览仅统计授权命名空间。集群连接、集群命令和交互式集群 Shell 需要完整集群管理员范围。超级管理员保留全局访问能力。

后端资源接口、WebSocket、任务中心创建/执行/重跑/后台执行以及 AIOps K8s 查询均执行范围检查。写入操作和授权调整记录审计，审计不存储 YAML、Secret 数据或 kubeconfig。

## Secret 与执行权限

Secret 内容查看、编辑预览和历史版本额外需要 `ops.k8s.secret.view`；普通 `ops.k8s.view` 只返回元数据。该权限仍与原有读写权限及集群/命名空间范围共同检查，不单独授予资源访问。

任务中心的创建、执行、重跑和执行器同时检查对应的 K8s manage / exec / kubectl 权限，不能仅凭任务执行权限绕过。未配置用户范围策略的账号沿用平台范围，不等于无需具体平台能力。

Pod exec、kubectl 和集群终端可以读取或修改集群内数据，应按敏感执行能力分配。超级管理员仍受账号启用状态及功能开关约束。撤权阻止后续请求和新连接，已有终端不会自动断开。

## 升级与验证

在维护窗口执行完整 `python manage.py migrate --noinput`，重启应用和相关 worker。旧账号无范围策略时沿用平台范围；需要收紧的用户应显式配置集群与命名空间。

隔离环境回归入口：

```bash
cd backend
python manage.py test ops.test_k8s_workbench ops.test_k8s_capacity ops.test_k8s_logs rbac ops.test_host_tasks aiops.test_langgraph_k8s --noinput
```

界面变更还需生产构建及浏览器验证资源列表、Secret 门禁、YAML 差异、授权弹窗、终端连接释放、日志翻页、三主题和窄屏。真实集群验证应使用明确的测试资源，不能把演示集群结果视为生产可用性证明。
