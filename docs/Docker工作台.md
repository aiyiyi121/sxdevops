# Docker 工作台

Docker 环境的环境管理、容器管理和镜像管理统一采用 K8s 工作台的紧凑布局。

## 页面与交互

- 环境管理采用卡片选择与右侧概要，展示 Docker 版本、操作系统、架构、内核、存储驱动、CPU / 内存容量、容器及镜像数量；卡片操作靠底部对齐。
- 选择环境后保留当前上下文，容器、镜像页均可直接切换环境，过期请求不会覆盖新环境的数据。
- 资源列表默认每页 20 条，可选择 50 / 100 条，搜索、状态筛选、分页只挂载当前页；操作菜单按需挂载。
- 自动刷新默认关闭，可选择 15 / 30 / 60 秒，后台页面或日志、详情、终端弹窗打开期间暂停刷新。
- 启停、重启、删除容器、删除镜像和清理悬空镜像均显示目标环境并二次确认；镜像 ID 去重，同一 ID 的多个标签会一起受影响，不强制删除被容器占用的镜像。
- 容器和镜像详情提供概要、JSON 复制与全屏，弹窗仅保留内容区域的滚动条。
- 容器日志复用 K8s 日志窗口：首屏读取最近 500 行，向上继续浏览 Docker 日志驱动保留的历史，窗口最多保留 3 页，每页上限 512 KiB，不额外添加时间戳。日志轮转、会话过期或采集失败会明确提示。
- 运行中的容器可进入交互式终端，支持 Shell 选择、复制粘贴、清屏、全屏、重连和下载会话。Tab 直接发送给容器内 Shell，补全能力取决于容器已有 Shell 及 bash-completion 配置。

## 权限

在系统管理的用户 / 角色权限配置中统一分配：

| 权限 | 范围 |
| --- | --- |
| `ops.docker.view` | 环境概要、容器、镜像、详情及日志 |
| `ops.docker.manage` | 环境维护、容器启停删除、镜像清理 |
| `ops.docker.exec` | 容器交互终端，同时需要查看权限 |

内置运维管理员包含容器终端权限，只读访客不包含管理及终端权限。所有账号统一检查实际角色权限，不存在用户名专属终端特权。终端在后端校验令牌、用户有效性和权限，固定执行 `docker exec` 进入目标容器，不能用此入口打开主机 Shell。

写操作和进入终端记录操作者与资源，不记录 SSH 密码或会话命令内容。

## 性能与资源管理

环境概要短缓存 10 秒，容器 / 镜像列表短缓存 5 秒；手动刷新绕过缓存，修改后失效缓存。列表读取失败不回填旧环境数据。

SSH 标准输出和错误输出同时读取，避免大输出堵塞后等待退出状态；命令输出上限 8 MiB，查询和连接均有超时，异常路径也释放连接和通道。

历史日志流式落入临时文件，游标绑定当前用户、环境和容器，共用 K8s 日志的并发限制、磁盘空间保护与过期清理。终端最多持续 30 分钟，15 分钟无输入则断开，关闭弹窗后释放 WebSocket、SSH、终端实例和尺寸观察器。
